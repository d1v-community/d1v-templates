| Twin pair | What stays the same | What is unique |
|-----------|---------------------|----------------|
| **assistant-saas** ↔ **prompt-library** | Login, billing, Neon schema | Command console vs curated catalog |
| **client-portal** ↔ **internal-dashboard** | Login, billing, role gating | External client service vs internal operator surface |

<a id="-what-every-template-includes"></a>

## ◆ What every industry template includes

- **passwordless email auth** — no passwords, no resets, no friction.
- **Neon / PostgreSQL + Drizzle** — serverless Postgres, typed schema, and a direct migrate/seed workflow.
- **hosted checkout + `/pricing`** — payments are wired to Payment Hub from the first commit.
- **local env bootstrap** — `scripts/bootstrap-local-env.mjs` pulls real `.env` from `d1v-server`.
- **template-local `AGENTS.md`** — each template ships its own execution contract and validator registry.
- **industry copy in `app/constants/site.ts`** — the headline, FAQ, AI assistant voice, and product modules are tuned per template.
- **industry theme in `app/constants/site-theme.ts`** — six families (ai, business, commerce, creator, education, local) drive the visual system.

<a id="-publication-workflow"></a>

## ◆ Publication workflow

```text
  foundations/remix-neon-auth-pay     (the single source of truth)
              │
              ▼
  industries/<category>/<template>   (generated, customized, verified)
              │
              ▼
  d1v-community/<template>-template  (GitHub template-mode repo)
              │
              ▼
  templates.json                     (registry entry, machine-readable)
```

1. **Generate** the industry directory from `remix-neon-auth-pay`.
2. **Pull a real `.env`** from `d1v-server` into the template.
3. **Run** `db:migrate`, `db:seed`, `typecheck`, and a targeted app verification.
4. **Push** the verified directory to `d1v-community/<name>-template`.
5. **Enable** GitHub template mode for that repository.
6. **Update** the root registry so `templates.json` points to the published repo URL.
